실생활 보안 수칙

보안은 특별한 기술보다 매일 반복하는 작은 습관에서 시작됩니다.
아래 수칙들을 확인하고 안전한 인터넷 사용 습관을 만들어 봅시다.

ACCOUNT

계정 관리

계정 탈취를 막는 첫 번째 방어선
  • 위험 비밀번호 재사용
  • 대응 서비스별 다른 비밀번호
  • 강화 2단계 인증(MFA)
  • 관리 로그인 기록 확인

하나의 계정이 해킹되면 이메일, SNS, 클라우드까지 연쇄적으로 침해될 수 있습니다. 특히 이메일 계정은 모든 계정의 중심이므로 가장 강하게 보호해야 합니다.

ACCOUNT

비밀번호 관리

강력한 비밀번호 설정의 중요성
  • 기본 최소 12자 이상
  • 구성 대/소문자, 숫자, 특수문자 혼합
  • 회피 생일, 이름 포함 금지
  • 도구 비밀번호 관리자 사용

비밀번호 관리자를 사용하면 각 서비스마다 복잡한 비밀번호를 사용할 수 있습니다. 무료 및 유료 솔루션 모두 이용 가능하며, 자동 채우기 기능으로 편의성도 높입니다.

ACCOUNT

복구 수단 설정

계정 복구를 위한 사전 준비
  • 필수 복구용 이메일 등록
  • 필수 휴대폰 번호 등록
  • 선택 보안 질문 설정
  • 관리 정기적 갱신

계정이 탈취되었을 때 신속한 복구를 위해 복구 수단을 미리 등록해야 합니다. 보조 이메일과 휴대폰 번호를 정확하게 유지하세요.

ACCOUNT

2단계 인증 설정

추가 보안 계층의 중요성
  • 방식 SMS, 이메일, 앱 중 선택
  • 권장 인증 앱 사용 (가장 안전)
  • 주의 복구 코드 안전 보관
  • 설정 주요 계정 우선 적용

2단계 인증은 비밀번호가 탈취되어도 계정 접근을 차단합니다. Google Authenticator, Microsoft Authenticator 등 앱 기반 인증이 SMS보다 안전합니다.

DEVICE

기기 보안

개인정보가 모여있는 핵심 장치
  • 위험 업데이트 미적용
  • 대응 OS 및 앱 최신 유지
  • 강화 잠금 화면 설정
  • 주의 출처 불명 앱 설치 금지

스마트폰과 PC는 인증 수단이기 때문에 침해되면 계정 보호가 무너질 수 있습니다. 특히 출처 불명의 앱이나 프로그램 설치는 악성코드 감염의 주요 원인이 됩니다.

DEVICE

보안 업데이트

알려진 취약점 패치의 필수성
  • 중요 보안 업데이트 우선 설치
  • 권장 자동 업데이트 활성화
  • 관리 정기적 재시작
  • 확인 업데이트 이력 점검

보안 업데이트는 발견된 취약점을 즉시 차단합니다. 업데이트를 미루면 해커의 공격 대상이 될 확률이 높아집니다. 자동 업데이트 설정을 권장합니다.

DEVICE

백신 및 방화벽

악성코드로부터의 방어
  • 필수 백신 프로그램 설치
  • 필수 방화벽 활성화
  • 관리 정기적 바이러스 검사
  • 주의 의심 파일 격리

Windows Defender, macOS 보안 기능 등 OS 기본 백신도 효과적입니다. 정기적 검사와 자동 격리 기능을 활용하여 악성코드로부터 보호하세요.

DEVICE

공용 WiFi 보안

무선 네트워크 사용 시 주의사항
  • 금지 공용 WiFi에서 결제
  • 금지 공용 WiFi에서 민감정보 입력
  • 권장 VPN 사용
  • 확인 정식 네트워크명 확인

카페, 공항의 무료 WiFi는 해킹하기 쉬워 개인정보 탈취 위험이 큽니다. VPN(가상 사설망)을 사용하거나, 계정 확인 등 민감한 작업은 이동 데이터(4G/5G)를 사용하세요.

PHISHING

피싱 대응

사용자의 심리를 노리는 공격
  • 위험 긴급/무료 문구
  • 대응 URL 주소 확인
  • 강화 공식 사이트 직접 접속
  • 확인 발신자 검증

피싱은 기술보다 심리를 이용하는 공격입니다. 링크를 바로 누르기보다 주소를 직접 입력하거나 공식 앱을 통해 접속하는 습관이 중요합니다.

PHISHING

이메일 피싱

이메일을 통한 사기 탐지법
  • 의심 낯선 발신자 이메일
  • 확인 발신자 이메일 주소 정확성
  • 점검 첨부 파일 확장자
  • 검증 공식 채널에서 재확인

은행, 카드사 이름을 사칭한 이메일은 거의 피싱입니다. 정상 발신자 이메일 주소는 공식 홈페이지에서 확인하고, 첨부 파일 실행 전 바이러스 검사를 하세요.

PHISHING

스미싱 주의

문자 메시지를 통한 피싱
  • 의심 미처리 요금 안내
  • 의심 배송 정보 단축 URL
  • 대응 URL 클릭 금지
  • 보고 신고 번호로 신고

배송, 요금, 상금 당첨 등의 명목으로 온 문자의 URL은 클릭하지 마세요. 공식 앱이나 직접 입력한 주소로 접속하여 정보를 확인하세요.

PHISHING

SNS 피싱

소셜 미디어를 통한 사기
  • 주의 팔로워 증가 이벤트
  • 주의 경품 당첨 알림
  • 확인 공식 계정 확인 배지
  • 거절 DM 링크 클릭 금지

SNS에서 "팔로워 100만 축하", "경품 당첨" 등의 메시지와 링크는 거의 사기입니다. 공식 계정에는 인증 배지가 있으니 확인하고, DM 링크는 절대 클릭하지 마세요.

DATA

데이터 보호

한 번 잃으면 되돌릴 수 없는 자산
  • 위험 랜섬웨어
  • 대응 정기 백업
  • 강화 클라우드 + 외장 저장
  • 관리 최소 정보 저장

데이터 유출은 장기간 악용될 수 있어 피해가 큽니다. 중요한 파일은 반드시 여러 위치에 분산 저장하고 민감한 정보는 최소한으로 보관해야 합니다.

DATA

백업 전략

3-2-1 백업 규칙
  • 기본 3개 복사본 유지
  • 저장 2가지 미디어에 저장
  • 위치 1개는 다른 장소에 보관
  • 확인 정기적 복구 테스트

데이터 백업은 정기적이고 분산되어야 합니다. 클라우드 스토리지와 외장 하드 드라이브를 함께 사용하고, 가끔은 복구 가능한지 테스트하세요.

DATA

개인정보 삭제

불필요한 정보 즉시 폐기
  • 정책 필요 정보만 저장
  • 삭제 사용 종료 시 즉시 제거
  • 주의 휴지통 비우기
  • 관리 계정 정보 정기 점검

신용카드 번호, 주민번호, 비밀번호 등을 파일이나 메모에 저장하지 마세요. 클라우드에 자동 저장되는 파일도 확인하고 불필요한 정보는 삭제하세요.

DATA

파일 암호화

민감한 파일 보호 방법
  • 도구 Windows BitLocker, Mac FileVault
  • 클라우드 암호화 스토리지 이용
  • 파일 개별 파일 암호화
  • 관리 암호화 키 안전 보관

민감한 파일이나 폴더는 암호화하여 보호하세요. 전체 드라이브 암호화는 기기 분실 시 데이터 탈취를 방지하며, 클라우드 계정도 암호화된 스토리지 서비스를 선택하는 것이 좋습니다.
